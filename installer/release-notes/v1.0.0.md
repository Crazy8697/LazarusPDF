Lazarus PDF 1.0.0.

- Icon fonts are no longer installed into Windows. Older versions (through the QtAwesome library) copied 12 icon fonts into your user fonts folder and registered them in the registry. Lazarus PDF now loads the one icon font it uses, Material Design Icons, privately from its own folder, and ships only that font.
- The fonts older versions left behind are cleaned up: on the first start of 1.0.0, and when you uninstall. Only files that are byte for byte QtAwesome's own copies are removed, with their registry entries; no other font is ever touched. A font Windows has in use is removed on a later start.
- The third-party notices now list exactly what ships, including the Material Design Icons license (Pictogrammers Free License: fonts and icons under Apache-2.0).
- Every icon looks exactly as before.

Another program that still uses QtAwesome the old way may put those fonts back. That's harmless; they're its own.

Install: download LazarusPDF-Setup.exe (or LazarusPDF-Setup-1.0.0.exe) and run it, or use Help > Check for updates. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
LazarusPDF-Setup-1.0.0.exe.sha256 holds the installer's SHA-256 checksum. Lazarus-Setup-1.0.0.exe and
Lazarus-Setup.exe are the same installer under the old names, for Lazarus 0.21.0's updater and older links.
