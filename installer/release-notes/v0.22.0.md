Lazarus PDF 0.22.0: Lazarus is now Lazarus PDF.

Same program, new name. It now installs to C:\Program Files\LazarusPDF as LazarusPDF.exe, and this repository moved to Crazy8697/LazarusPDF (the old address redirects here).

Upgrading from Lazarus 0.21.0:

- Help > Check for updates in Lazarus 0.21.0 finds this release and upgrades in place, or run the installer yourself.
- The old Program Files\Lazarus folder, its shortcuts and its Apps entry are removed. You get one "Lazarus PDF" entry in Apps.
- Your settings move over on their own: recent files, output folder, undo memory, the update-check choice, window layout and everything else, plus your saved signatures.
- If Lazarus was your default PDF reader, double-clicked PDFs keep opening in Lazarus PDF. Windows only lets you change the default yourself, so to show the new name there, pick Lazarus PDF once in Settings > Default apps (Lazarus PDF's Settings has a button for it).

Install: download LazarusPDF-Setup.exe (or LazarusPDF-Setup-0.22.0.exe) and run it. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
LazarusPDF-Setup-0.22.0.exe.sha256 holds the installer's SHA-256 checksum. Lazarus-Setup-0.22.0.exe and
Lazarus-Setup.exe are the same installer under the old names, for Lazarus 0.21.0's updater and older links.
