Lazarus 0.21.0: Searchable PDF and Rebuilt pages from Extraction.

New in Extraction mode, under Export:

- Searchable PDF: the original pages exactly as they look, with your corrected text (every word you changed and every gap you filled in) as an invisible, selectable, searchable layer behind them. Corrected words sit where the words they replace are. Pages that already have a real text layer keep it.
- Rebuilt pages: a brand-new, clean PDF typeset from your corrected text: crisp text pages, no scan images, the same page sizes, figures kept where they came.
- Both write a new file and never touch the original.

Also:

- The editor's OCR page tool and Searchable PDF share one text-layer engine.
- The last placeholders are gone: the import dialog's greyed mode choices, the unfinished View > Page layout menu and its toolbar button, and the "greyed tools" note in the Document panel.

Install: download Lazarus-Setup.exe (or Lazarus-Setup-0.21.0.exe) and run it, or use Help > Check for updates in Lazarus 0.20.0. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
Lazarus-Setup-0.21.0.exe.sha256 holds the installer's SHA-256 checksum.
