Lazarus 0.19.1

- Update checker: at startup (Settings > "Check for updates at startup", on by default) Lazarus asks
  GitHub for the latest release in the background and shows a bar when a newer one is out:
  Download and install / Skip this version / Later. Help > Check for updates... checks by hand.
- Updates download the installer, verify its SHA-256 against the published checksum, ask about any
  unsaved work, then upgrade this installation in place and start Lazarus again.
- Privacy: the only network requests are GitHub's latest-release lookup and, if you choose to
  update, the installer download. No telemetry.
