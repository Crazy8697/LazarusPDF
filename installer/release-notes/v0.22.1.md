Lazarus PDF 0.22.1: a clean title bar.

- The window title is now just "Lazarus PDF", in every mode and whatever is open. 0.22.0 showed the name twice ("Lazarus PDF - PDF Editor - Lazarus PDF"). The mode buttons and tabs already show the mode, the file and unsaved work.
- Dialog titles no longer repeat the program's name ("Settings", "Import PDF").
- Plainer punctuation in messages, tooltips and the review files' gap and figure markers ("[[FILL IN - p.N]]").
- Under the hood: the first-start move of Lazarus 0.21.0 data never touches the real registry during test runs, with a self-test check that guards it.

Install: download LazarusPDF-Setup.exe (or LazarusPDF-Setup-0.22.1.exe) and run it, or use Help > Check for updates. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
LazarusPDF-Setup-0.22.1.exe.sha256 holds the installer's SHA-256 checksum. Lazarus-Setup-0.22.1.exe and
Lazarus-Setup.exe are the same installer under the old names, for Lazarus 0.21.0's updater and older links.
