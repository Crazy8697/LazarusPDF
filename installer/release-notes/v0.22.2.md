Lazarus PDF 0.22.2: a new icon.

- A new program icon: a relay node on a page, with scan lines materializing below it. It's used for the program, its window and taskbar button, the About box, the installer and the Start menu and desktop shortcuts.
- Nothing else changed.

If Windows keeps showing the old icon on a shortcut or the taskbar for a while after updating, that's Windows' icon cache; it catches up on its own (a sign-out and back in also refreshes it).

Install: download LazarusPDF-Setup.exe (or LazarusPDF-Setup-0.22.2.exe) and run it, or use Help > Check for updates. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
LazarusPDF-Setup-0.22.2.exe.sha256 holds the installer's SHA-256 checksum. Lazarus-Setup-0.22.2.exe and
Lazarus-Setup.exe are the same installer under the old names, for Lazarus 0.21.0's updater and older links.
