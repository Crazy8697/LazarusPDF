Lazarus 0.20.0: the first public release.

Lazarus is a free, local PDF editor and reader for Windows (10 / 11, 64-bit), now open source under the
GNU AGPL-3.0.

- Read and navigate: tabs, thumbnails, Overview, bookmarks (also generated from headings), find, side-by-side compare.
- Mark up: highlights, drawings, shapes, notes, text boxes, stamps, callouts, measurements, signatures, images, links; an Annotations panel.
- Edit text in place, find and replace, whiteout, verified redaction.
- Pages: reorder, rotate, delete, insert, duplicate, crop, extract, merge, split; copy or drag pages between open PDFs.
- Forms, headers / footers, page numbers, Bates numbers, watermarks, metadata, flatten, compress, passwords (AES-256), OCR.
- PDFs from images or a scanner; export to Word, EPUB, Markdown, HTML, text or PDF; batch processing.
- Updates: a background check of this repository's latest release (can be turned off), SHA-256-verified downloads.
- New in this version: the About box, Help > Licenses (third-party notices), Help > Support DarkRelay.

Install: download Lazarus-Setup.exe (or Lazarus-Setup-0.20.0.exe) and run it. The installer isn't
code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway.
Lazarus-Setup-0.20.0.exe.sha256 holds the installer's SHA-256 checksum.
